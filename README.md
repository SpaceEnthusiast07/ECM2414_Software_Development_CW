## Project Versions
This project was written using Java 25 (Oracle OpenJDK 25) and the tests have been written using JUnit 6.

```text
cardsTest.zip/
├── src/                # Source code of project
├── test/               # Source code of tests and example pack files
├── libs/               # JUnit command line tools
├── bin/                # Byte code of project and tests
├── run_project.bat     # Shell scripts to compile and execute the project
├── run_project.sh
├── run_tests.bat       # Shell scripts to compile and execute the tests
├── run_tests.sh
└── README.md
```

## Executing the Project
To compile and run the project from the cardsTest.zip archive, run `run_project.bat` on Windows or `run_project.sh` on
MacOS and Linux. Ensure you are executing these shell scripts from within the unzipped cardsTest directory.

## Executing the Tests
To compile and run the tests from the cardsTest.zip archive, run `run_tests.bat` on Windows or `run_tests.sh` on MacOS
and Linux. Ensure you are executing these shell scripts from within the unzipped cardsTest directory.
